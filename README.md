# Imperial

**Imperial** — Docs, Sheets and Slides: a fast office suite for Windows, macOS and Linux.

Download the installer for your system from the [latest release](https://github.com/BLK-TTAUDI/imperial-releases/releases/latest). Installed copies update themselves (Settings ▸ Updates).
